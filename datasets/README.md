# Phase 2 Test Corpus

**All telemetry in this directory is synthetic and sanitized test data created for the SIH prototype. It is not production telemetry and must not be presented as real customer/device data.**

The five valid-source folders contain semantically comparable allow/deny/network events. `malformed/` contains deliberately broken records designed to prove safe failure. `unknown/` contains records that must never be forced through a known adapter. `expected/` defines machine-checkable expectations.
